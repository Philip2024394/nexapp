## What failed

**OpenNext `Building server function: default...` phase.** Raised:

```
Error: EPERM: operation not permitted, symlink
  'C:\...\node_modules\@aws-sdk\client-s3'
  -> 'C:\...\.open-next\server-functions\default\.next\node_modules\@aws-sdk\client-s3-ecbef8e33fd0b8f0'
    at symlinkSync (node:fs:2359:11)
    at copyTracedFiles (@opennextjs/aws/.../copyTracedFiles.js:237)
```

This is a well-known Windows limitation — unprivileged processes cannot
create NTFS symlinks unless:
- the shell is running elevated (Administrator), OR
- Windows **Developer Mode** is enabled (one-time system setting), OR
- the build runs inside WSL2 / Linux / macOS.

The adapter itself prints a banner at startup:

```
WARN OpenNext is not fully compatible with Windows.
WARN For optimal performance, it is recommended to use
     Windows Subsystem for Linux (WSL).
WARN While OpenNext may function on Windows, it could encounter
     unpredictable failures during runtime.
```

So the failure is **tooling · platform · solved** — not a nexapp code
defect.

### Turbopack whole-project tracing warning

```
./src/lib/nex/idempotency/store.ts:53:8
Warning: Dynamic filesystem access causes tracing of the whole project
   51 | function ensureDir(): void {
   52 |   const dir = idempotencyDataRoot();
 > 53 |   if (!existsSync(dir)) mkdirSync(dir, { recursive: true });
```

The dynamic `path` passed to `existsSync` / `mkdirSync` tells Next's
tracer *"I might read anywhere"*. Downstream effect: the entire project
tree may be included in the Workers bundle, pushing it toward the 25MB
compressed limit.

Import chain:
```
src/lib/nex/idempotency/store.ts
  ← src/lib/nex/idempotency/middleware.ts
  ← src/lib/nex-native/business-trial/idempotency.ts
  ← src/app/api/nex-native/trial/start/route.ts
```

Fix path (recommended · **not applied here**):

```ts
// make the path statically resolvable so the tracer knows the scope
const dir = path.join(process.cwd(), "data", "idempotency");
if (!existsSync(/*turbopackIgnore: true*/ dir)) {
  mkdirSync(dir, { recursive: true });
}
```

OR gate `ensureDir()` behind `process.env.NODE_ENV !== "production"`
if the filesystem branch is dev-only.

Decision deferred to Gate 3 remediation (owned by the `pg` /
filesystem workstream).
