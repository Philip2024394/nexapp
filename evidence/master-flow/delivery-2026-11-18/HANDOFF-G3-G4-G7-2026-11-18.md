## 2 · G3 · Replace `estimateBikeFareBetween` in the cart path with `quoteLocalDelivery`

### Current state (BUILT-UNWIRED)

The cart path in `sendCartOrderAction` at `_actions.ts:2755-2801` parses a client-supplied `delivery_quote` object (kind free/estimate/unknown + optional distance/fare/ETA) and persists it **without re-computing fare on the server from seller rings**. Any seller-ring-based authority lives only in the pure library.

### Target edit

**File:** `src/app/nex-native/_actions.ts`
**Insertion point:** immediately after line 2801 (after `deliveryQuote` is fully parsed from the client payload) and **before** the ownership checks at line 2803.
**Prerequisite:** resolve the shop's `delivery.radii` from the authoritative `nex_business` row (owner may elect a dedicated helper · see §5 below).

```ts
// G3 · Server-side authoritative local-delivery quote.
// Pure · deterministic · does NOT trust client numbers.
import { quoteLocalDelivery } from "@/lib/nex-native/delivery/local-delivery-quote";
import { extractDelivery } from "@/lib/nex-native/catalogue/delivery-spec";

// Resolve seller's rings once per cart submission.
const sellerBusiness = await /* existing nex_business select */;
const sellerDelivery = extractDelivery(sellerBusiness.spec);
const authoritative = quoteLocalDelivery({
  rings: sellerDelivery.local.radii,
  origin: sellerDelivery.local.origin,
  destination: /* buyer delivery-address lat/lng · resolved upstream */,
});
if (authoritative.kind === "out_of_range") {
  redirect(
    "/nex-native/cart?send_error=" +
      encodeURIComponent("Shop does not deliver to this address"),
  );
}
if (authoritative.kind !== "quoted") {
  redirect(
    "/nex-native/cart?send_error=" +
      encodeURIComponent("Delivery unavailable"),
  );
}
```

### Semantics

- **Inclusive ring boundary:** `quoteLocalDelivery` picks the smallest ring where `km ≥ distanceKm` (library-test-locked).
- **Straight-line labelling:** the quote's `distanceKind` is `"straight_line_haversine"` · no road-routing promise.
- **No silent zero:** out-of-range + missing-origin + missing-destination all return non-`quoted` discriminants · the server MUST not fall through to a zero-fare path.

## 3 · G4 · Wire `isSubmittedLocalQuoteAuthentic` + `isSubmittedExportQuoteAuthentic` into `sendCartOrderAction`

### Current state (BUILT-UNWIRED)

`sendCartOrderAction:2755-2801` validates only **structure** of the client `delivery_quote` (number vs string, finite vs NaN). It does **not** compare the client's submitted fare / currency / distance-truncation against the server-authoritative quote from G3. A tampered client can therefore persist an artificially low fare on an otherwise-valid cart submission.

### Target edit

**File:** `src/app/nex-native/_actions.ts`
**Insertion point:** immediately after the G3 block (so immediately after line 2801 + G3 insert), before item verification at line 2810-ish.

```ts
// G4 · Reject client-submitted quote tampering.
// `authoritative` comes from the G3 block above.
import {
  isSubmittedLocalQuoteAuthentic,
} from "@/lib/nex-native/delivery/local-delivery-quote";
import {
  isSubmittedExportQuoteAuthentic,
} from "@/lib/nex-native/delivery/export-shipping-quote";

if (deliveryQuote && deliveryQuote.kind === "estimate") {
  const authentic = isSubmittedLocalQuoteAuthentic(
    {
      fare_pence: deliveryQuote.fare_pence ?? -1,
      currency: deliveryQuote.currency ?? "IDR",
      distance_km_truncated: Math.trunc(deliveryQuote.distance_km ?? -1),
    },
    authoritative,
  );
  if (!authentic) {
    redirect(
      "/nex-native/cart?send_error=" +
        encodeURIComponent("Delivery quote mismatch · please refresh"),
    );
  }
}

// For export shipments, use the export authoritative quote + authenticity
// check instead · see §4 for the export path.
```

### Semantics (library-locked)

- `isSubmittedLocalQuoteAuthentic` compares **fare pence (exact)**, **currency (exact)**, and **integer-truncated distance km (exact)**. Floating-point distance drift that still truncates to the same integer passes · changes in fare or currency fail.
- Export counterpart `isSubmittedExportQuoteAuthentic` compares per-country ISO, fare pence, currency.

Add to the same new test file `cart-g3-authoritative-delivery.test.ts`:

6. Submits with tampered `distance_km` that still truncates to the same integer · asserts success (library-correct behaviour, prevents false positives on floating-point drift).
